# jasgh14.github.io

Static GitHub Pages portfolio refactored to a multi-page architecture with modular CSS, modular vanilla JS, and data-driven content files.

## Pages
- `index.html`
- `cv.html`
- `projects.html`
- `contact.html`
- `404.html`

## Local preview
Use any static file server from the repository root.

Example:
```bash
python3 -m http.server 8080
```
Then open `http://localhost:8080`.
